# Libft

## Description

**Libft** is a project from the 1337 (42 Network) curriculum. The goal is to recreate a set of standard C library functions and develop a personal library that can be reused in future C projects.

This project helps strengthen understanding of pointers, memory allocation, strings, and linked lists.

## Features

### Part 1 — Libc Functions

Reimplementations of standard C library functions, including:

- Character checks and conversions
- String length and manipulation
- Memory manipulation
- Memory comparison and searching
- Memory allocation and duplication

### Part 2 — Additional Functions

Additional functions for working with strings and memory, including:

- String extraction and concatenation
- String trimming and splitting
- Integer conversion
- String iteration and mapping
- Writing characters, strings, and numbers to file descriptors

### Part 3 — Linked Lists

Linked-list functions for creating, adding, deleting, and iterating through list elements.

## Instructions

### Compilation

Run the following command from the project directory to compile the library:
- make
This generates the static library libft.a.

### Makefile Rules

- make or make all: Compiles the source files and creates the library.
- make clean: Removes object files (.o).
- make fclean: Removes object files and libft.a.
- make re: Performs a clean rebuild of the library.
